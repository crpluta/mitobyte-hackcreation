# Diablo-like Todo Tracker - Hackathon Project

## Project Overview
A 3D habit/todo tracker game built in Godot 4.x where players interact with NPCs (like Deckard Cain from Diablo) to manage their real-life tasks gamified as quests.

## Timeline
- **Duration**: 5 hours (hackathon)
- **Team**: Split team - this repo handles Godot game, other team handles LLM/JSON generation

## Technical Stack
- **Engine**: Godot 4.4.1
- **Language**: GDScript
- **Graphics**: Simple shapes and colors (no custom assets due to time)
- **Audio**: None (time constraint)
- **Data Format**: JSON files generated by other team

## Core Gameplay Loop
1. Player talks to Deckard Cain NPC
2. Can manually enter todos OR Cain assigns todos
3. Player assigns todos to worker NPCs
4. Worker NPCs complete todos over time
5. Completion awards XP and Gold
6. Player spends rewards in shop

## Integration Points
- **JSON Format**: Pre-generated by other team (same repository)
- **LLM Processing**: Other team splits complex tasks into subtasks
- **Data Flow**: Read JSON files → Display in game → Update completion → Save progress

## Development Constraints
- No custom 3D assets (use primitives: cubes, spheres, capsules)
- No audio/sound effects
- Focus on game loop over polish
- Must be MVP-complete in 5 hours

## Key Technical Challenges
1. NPC interaction system (dialog/UI)
2. Todo state management
3. Worker NPC assignment logic
4. Progress tracking and persistence
5. Shop/reward system

## Success Criteria
- Can load todos from JSON
- Can interact with Deckard Cain
- Can assign todos to workers
- Workers complete tasks
- XP/Gold rewards work
- Can buy items from shop
