Create a new Godot 4.x scene file with the provided name. Include:
- Appropriate root node (Node3D for 3D scenes, Control for UI)
- Basic scene structure
- Placeholder comments for common additions

Usage: /quick-scene SceneName [type]
Where type is: 3d, ui, or character (defaults to 3d)
